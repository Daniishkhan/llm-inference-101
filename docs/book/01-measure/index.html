Module 1 of 20 · LLM inference in Python

Measure first

Ten chapters that take you from "it feels slow" to a number you can trust: two clocks, a hundred calls instead of one, the typical call and the slow tail, a histogram drawn in the terminal, and a line timer that points at the slow line. By the end you have typed a benchmark harness that every later module measures itself with.

What this book is

This is the book of Module 1, the first of the 20 modules in goal.md, the plan of the whole course. The module's spec, its contract and its milestones are in modules/01-measure/README.md; this book teaches everything the spec needs, one idea at a time.

What you build is python -m llm101.bench: a program that calls a function many times, times every call with a wall clock and a CPU clock, and prints p50, p95 and p99, a histogram of the times, and, with --profile, the slowest lines of the function. Along the way you meet quickselect, the selection algorithm that finds one position of a sorted list without sorting it, and the drills of the module, which are hashing problems.

The rule of the course holds on every page. The book teaches each mechanism with complete, runnable examples on a different problem (a kettle, a café queue, a hand of cards, a weather report), and never shows a function of your contract or a drill. Chapter 8 gives you the milestones and the hint ladders; the code is yours to type.

How to read it

Read in order; each chapter uses only what came before it. Type every example into scratch/ and run it with uv run python scratch/NAME.py, rather than copying it. When a program's output is shown, compare yours with it line by line. Answer each check-yourself question before you open its answer. Tick the box at the bottom of a chapter when you have worked through it; your progress is saved in this browser.
