Module 2 of 20 · LLM inference in Python

Tokenizer

Ten chapters that take you from "a model reads numbers" to GPT-2's own tokenizer, typed by hand: UTF-8 bit by bit, byte-pair encoding trained on a text of your own, encoding by rank, GPT-2's two files, and a heap over a linked list that makes a long word fast. By the end, your ids match GPT-2's on every test, and you can say what a sentence costs before a model sees it.

What this book is

This is the book of Module 2, the second of the 20 modules in goal.md, the plan of the whole course. The module's spec, its contract and its milestones are in modules/02-tokenizer/README.md; this book teaches everything the spec needs, one idea at a time.

What you build is python -m llm101.tokenizer: a program that turns any text into GPT-2's token ids and back, and shows you where each token begins and ends. Under it sit the pieces of a byte-level BPE (byte-pair encoding) tokenizer: UTF-8 written out with shifts and masks, a trainer that counts neighbouring pairs and merges the most frequent, an encoder that replays the merges, a loader for GPT-2's vocab.json and merges.txt, and a fast encoder built from a heap and a linked list. The drills of the module are on those last two: heaps and linked lists.

The rule of the course holds on every page. The book teaches each mechanism with complete, runnable examples on a different problem (a colour packed into one number, temperatures from day to day, a hospital's triage queue, a playlist with songs removed), and never shows a function of your contract or a drill. Chapter 8 gives you the milestones and the hint ladders; the code is yours to type.

How to read it

Read in order; each chapter uses only what came before it. Type every example into scratch/ and run it with uv run python scratch/NAME.py, rather than copying it. A concept chapter has at most eight programs, so that each one can be covered and rebuilt from memory inside the read block. When a program's output is shown, compare yours with it line by line. Answer each check-yourself question before you open its answer. Tick the box at the bottom of a chapter when you have worked through it; your progress is saved in this browser.
