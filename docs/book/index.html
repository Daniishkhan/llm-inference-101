The course · one book per module

LLM inference in Python, typed by hand

A self-paced course in 18 modules and a capstone. You learn data structures and algorithms by building the parts of an inference engine in Python, then you read vLLM, then you serve open models. Every solution is typed by you; the books teach each mechanism on a different problem and never show your code.
